# Idaho POE Study Quiz

A free, independent study tool for Idaho Port of Entry inspectors.

**[Open the quiz](https://shellvandenberg.github.io/poe-quiz/)**

## Study by section

Practice eight subjects separately:

- Weight
- Size
- Registration
- Hazardous materials
- Cargo securement
- Equipment
- Rover
- Weigh-in-motion and bypass

Each section has its own saved progress and results. Review missed questions with the correct answers and source references to identify areas that need more attention.

## Practice grading

Completed sections receive a separate grade:

- **PASS:** At least 90% correct on a finished section.
- **NEEDS WORK:** Below 90% correct on a finished section.
- **IN PROGRESS:** Questions remain unanswered.

This is a practice threshold, not confirmation of the official test's passing requirements.

## Save and resume

Progress saves automatically on the device and browser you're using. Return to resume a section where you left off, or restart that section after confirming.

Progress does not sync between devices or browsers. Clearing browser data can erase saved progress.

## Offline use

Open the online quiz while connected to the internet first. After it loads, it supports offline use and can be added to your device's home screen. Reopen it online to receive updates.

## References and corrections

Questions reference Idaho Code, federal regulations, IDAPA rules, and relevant ITD study materials where applicable. Always consult current official sources for operational decisions.

Found an error? Open an issue in this repository with the question wording, suggested correction, and supporting reference. Please don't include confidential information.

## Disclaimer

This is an independent study resource. It is not an official Idaho Transportation Department test or publication, and it does not replace official training, policies, or current law.
